## 1. 원천 필드 대응 — 대조로 확정

경기데이터드림 API 명세 페이지가 동적 렌더링이라 필드 설명을 읽지 못했다.
대신 **기존 행안부 적재분과 이름이 같은 168건을 전수 대조**했다.

| 경기도 API | DB 컬럼 | 일치 |
|---|---|---|
| `EMBEL_INSTL_YN` / `EMBEL_INSTL_PLC` | `emg_bell_yn` / `emg_bell_location` (비상벨) | **168/168** |
| `INSTL_YN` / `PLC_NM` | `diaper_table_yn` / `diaper_table_location` (기저귀교환대) | **168/168** |
| `TOILET_YN` | `cctv_yn` (입구 CCTV) | **168/168** |
| `INSTL_YM` `202503` | `install_dt` `2025-03` | 형식 변환 |
| `PROC_CONT` / `TOILET_POSESN_DIV` | `waste_process_type` / `owner_type` | 168/168 |

원천에 **없는** 컬럼: `basis`, `open_time_detail`, `safety_target_yn` → NULL.
`MALE_FEMALE_CMNUSE_TOILET_YN`(남녀공용) → `unisex_yn` — 이성 활동지원사와 동행하는 이용자에게 필요한 정보라 01 v1.4.0 에서 컬럼을 추가해 v1.12.0 부터 적재한다(안양 243건 중 `Y` 4건).

## 2. 개방시간 — 이 원천의 한계

`OPEN_TM_INFO` 는 `상시`(139) / `정시`(104) 두 값뿐이다. **"지금 열려 있는지"는 이 원천만으로 알 수 없다.**

기존 행에는 `open_time_detail`(예: `09:00~18:00`)이 149건 있었다(2022~2024년 행안부 표준데이터 출처).
이름+주소가 같은 기존 행을 제자리 갱신하면서 새 값이 없는 `open_time_detail` 은 유지한다(147건).
이름만 같은 다른 행의 값을 복제하지는 않는다.

- 갱신 후: `정시` 104건 중 **75건은 시간대 있음 · 29건은 없음** / `상시` 139건 중 67건에 `00:00~24:00` 류
- ⚠️ 유지된 상세시간은 **2022~2024년 값**이다. 원천 기준일(2025-07-17)과 시점이 다르다.
  `정시` 의 정의와 시간대는 경기도·안양시에 문의해야 확정된다(미해결).

## 3. 적재 방식 — (이름+주소) 매칭 동기화

이 테이블엔 원천 고유키가 없다(인덱스: PK·sido·좌표·(구분,이름)). 전국에 이름+도로명주소 중복이
이미 1,786건이라 단순 INSERT 는 중복을 쌓는다. 전량 논리삭제 후 재적재는 실행마다 PK 가 바뀌고 삭제 행이
누적되므로 채택하지 않았다.

`db_mobility.sync_public_toilets()` — **한 트랜잭션**에서

1. 기존 활성 행 선택: `sido_code` 일치 + (도로명·지번이 `GG_TOILET_ADDR_FILTER` 로 시작
   **또는** 새 행 주소에서 뽑은 `○○구` 접두어로 시작 — `만안구 안양로 317` 류 대응)
2. 매칭 키 = (이름, 정규화 주소). 주소는 공백·괄호 병기를 제거하고 지역 접두어(`경기도 안양시`)를 뗀 뒤
   도로명·지번 중 하나라도 같으면 같은 시설로 본다. 같은 키의 기존 행이 둘 이상이면 매칭에서 제외(경고)
3. 매칭 → UPDATE(id 보존, `open_time_detail` 은 새 값 없으면 유지) / 미매칭 신규 → INSERT /
   미매칭 기존 행 → 논리삭제
4. 방어: 수집 0건이면 무동작. 수집 건수가 기존 활성 행의 70% 미만이면 원천 장애로 보고 중단

통합 테스트(`tests/test_gg_toilet_db.py`, DB 가 있을 때만 실행)가 [기존 행 → 1차 동기화 → 2차 재실행] 로
id 보존·상세시간 유지·동명 다른 주소 비복제·다른 지역 불변·급감 시 중단을 검증한다.

## 5. 후속

- 경로 서비스(02)·비서(12)는 이 테이블을 직접 읽지 않는다(09 API 만 `del_yn='N'` 으로 조회). 화장실 도구 연결은 별도 작업
- `정시` 정의·시간대 확인 문의 (경기도·안양시)
- 경기도 전체(11,217건)로 넓히려면 `GG_TOILET_ADDR_FILTER=경기도` — 기존 경기도 5,545행이 동기화 대상이 된다. **실행 전 검토 필요**
- `INSTL_YM` 에 미래 연월(`202511`)이 있다 — 원천 값 그대로 적재했다
- 좌표 없는 6건은 원천 결측. 지오코딩 보정은 이용 약관(저장 금지 원천 제외)을 확인한 뒤 판단

## 확인 못 한 것

- 경기도 API 의 공식 필드 정의(포털이 동적 렌더링). 대응은 168건 대조 결과이지 명세 확인이 아니다
- 논리삭제된 6건(연현마을·박석교·충훈공원·삼막애견공원·관악수목원·한가람어린이공원)의 폐쇄·개명 여부
